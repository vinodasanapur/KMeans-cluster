# K-Means Clustering on Iris Dataset

This project demonstrates unsupervised machine learning using the **K-Means clustering algorithm** on the classic **Iris dataset** using Python, Scikit-Learn, and Seaborn.

---

## 📌 Project Overview

The objective is to cluster Iris flowers into groups ($k=3$) based on their physical features and predict cluster membership on unseen test data.

- **Algorithm**: K-Means Clustering ($k=3$)
- **Library**: `scikit-learn`, `pandas`, `seaborn`, `matplotlib`
- **Data Split**: 80% Training (120 samples), 20% Testing (30 samples)
